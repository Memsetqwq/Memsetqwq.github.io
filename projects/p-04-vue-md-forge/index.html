VUE-md-Forge

Vue 3 Markdown 编辑器插件 · 字符自动配对 + 双栏源码预览 + 本地 KaTeX/highlight.js · CSP 友好 · 克莱因蓝 hljs

Demo Repo

VUE-md-Forge 是一个可作为 npm 包发布、也能独立运行的 Vue 3 Markdown 编辑器组件。 目标对标 Typora 的即时渲染(IR)体验,核心特色:字符自动配对 + 光标居中 + 洛谷式双栏源码预览 + 工具栏对齐 markdown-palettes。

它解决什么问题

md-editor-v3 等现成编辑器通常通过 unpkg / jsdelivr 远程加载 markdown-it、highlight.js、katex、字体,导致:

  • 严格 CSP 环境下被迫 no-highlight: true / no-katex: true
  • 生产环境没有代码高亮,没有数学公式
  • vue-i18n runtime compiler 引入 new Function 路径,触发 CSP unsafe-eval 警告

VUE-md-Forge 把 markdown-it / highlight.js / katex 全部作为 npm 依赖打入产物:

  • 零远程加载(unpkg / jsdelivr / cdnjs 全部不在依赖图里)
  • 无 new Function 路径
  • 全程不引入需要 eval 的动态代码
  • 可走强制 CSP

核心特性

字符自动配对(beforeinput 事件)

输入 (,自动补 ),光标居中。跳过模式:光标紧贴已存在的右符号时,按 ) 移过它,不重复插入。成对删除:Backspace 在 () 中间按一次,删两侧。代码块内静默:\`` 内的 `` `` 不触发配对。

ASCII 配对(7 组):()、[]、{}、""、''、 ``、* / _ / ~。 中文配对(5 组,v0.3.8 升级):《》 「」 『』 〈〉 〖〗。 skip-over 修复(v0.3.8):之前 ASCII ) 跳过逻辑是死代码 —— 现在对所有 ASCII / 中文 closing 都生效。

工具栏对齐 markdown-palettes

21 个按钮 + 4 个分隔符,完全复制 luogu-dev/markdown-palettes 的 defaultBtns:

加粗 · 删除线 · 斜体 · 水平线 · H1..H6 · 无序列表 · 有序列表 · 图片 · 链接 · 代码块 · 表格 · 隐藏/显示预览 · 全屏 · 滚动同步 · 主题切换 · 关于。

FontAwesome 5 实心图标,H1..H6 用文本字形(与上游 content: 'H'+level 一致)。

智能粘贴 HTML → Markdown

继承自 club-web 已验证的启发式:shell 命令自动围栏、here-doc 识别、行内码合并、列表碎片合并、图片占位符。

CSP 友好的渲染引擎

  • markdown-it@14 + @vscode/markdown-it-katex(已迁移到维护中的 fork,原 markdown-it-katex@3 与 markdown-it 14 不兼容)
  • 本地打包的 highlight.js@11(注册 ts / py / bash / xml / css / json / cpp / java / go / sql)
  • katex@0.16
  • XSS 净化:sanitizeRenderedMarkdown 在每次 render 后过滤危险标签

本站在用:v0.3.x

v0.3 起,本站 /projects/p-04-vue-md-forge 和所有项目详情页的 Markdown 正文统一由本项目的 MarkdownEngine SSR 渲染:

  • 标题自动 slug id(锚点跳转)
  • 代码块 hljs 配色(v0.3.9):暗色主题对齐 One Dark Pro: Night Flat,函数名 + 符号用克莱因蓝 #3D5AFE,token 区分清晰(蓝+紫+绿+橙+黄 + 红 + 青 + 灰)
  • 数学公式 KaTeX 渲染(本地字体,无 CDN)
  • 表格 / 引用 / GFM 任务清单原生

/forge 工具页(v0.3.6+)

/forge 上下堆叠两个独立编辑器,互不干扰:

Section 角色 内容
A · Playground 用户操作区 空白起步,localStorage 自动保存草稿
B · Showcase 功能演示 18 节 ~400 行 markdown(就是本文件)

中间用 1px 分隔线隔开。每个 section 都有自己的 tag + 一句话说明。

技术栈

  • Vue 3.5 + Vite 7 + TypeScript 5.8
  • markdown-it 14 + @vscode/markdown-it-katex + highlight.js 11 + katex 0.16
  • FontAwesome 5(@fortawesome/vue-fontawesome)

构建产物(npm run build:lib):

  • dist/vue-md-forge.js(ESM,~924KB)
  • dist/vue-md-forge.umd.cjs(UMD,~584KB)
  • dist/vue-md-forge.css(themes + preview + editor,~1.5MB,含 KaTeX 字体 base64)
  • dist/index.d.ts(类型)

上手

git clone git@github.com:CDUESTC-OpenAtom-Open-Source-Club/VUE-md-Forge.git
cd VUE-md-Forge
npm install
npm run dev          # vite dev server,port 5273
npm run build:lib    # 输出 dist/,可作为 npm 包发布

作为依赖使用:

import { MdEditor } from 'vue-md-forge';
import 'vue-md-forge/style.css';
