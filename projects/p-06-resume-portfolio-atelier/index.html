Resume-Portfolio-Atelier

个人简历 / 求职作品集模板 — React 18 + TypeScript + Vite,组件化的求职站点模板

Date 2026/10/01
Stack
ReactTypeScriptVite
Links
Repo

一个可复用的个人简历 + 求职作品集站点模板,基于 React 18 + TypeScript + Vite。

它解决什么问题

  • 现有的求职站点模板多数是 WordPress / Hexo / Jekyll,非组件化,改一次样式要全文搜替换
  • 单文件 HTML 简历虽然简洁,但不能体现组件化能力(而这是前端岗位的硬技能)
  • 在求职季里要快速产出有设计感、可定制、可直接部署的简历站点

模板特色

  • 纯前端:单页 React,构建产物 dist/ 可部署到任何静态托管
  • 组件化简历区块:Hero / Experience / Projects / Skills / Contact,各自一个 .tsx,删改自由
  • TypeScript 严格:所有数据走 schema,改 config 类型直接报错,避免简历里出现错别字 / 字段名 typo
  • 样式方案:原生 CSS Modules + CSS variables — 不引 Tailwind / styled-components,减少体积
  • 响应式 + 暗色模式

部署方式

git clone https://github.com/Memsetqwq/Resume-Portfolio-Atelier.git
cd Resume-Portfolio-Atelier
npm install
npm run dev      # 本地 http://localhost:5173
npm run build    # 产物在 dist/

dist/ 可直接上传到:

  • GitHub Pages
  • Vercel / Netlify
  • Cloudflare Pages
  • 任意静态托管(GitHub Pages 与本仓库的 Memsetqwq.github.io 通用模式)
