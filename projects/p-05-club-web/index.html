OpenAtom 开源俱乐部(电子科技大学成都学院)对外宣传 / 成员展示 / 项目聚合的官方站点。

注:club-web 源码仓库当前为私有,匿名 GitHub API 看不到,本页面元数据来自人工维护。

项目定位

俱乐部的对外窗口,服务三个角色:

  • 潜在成员:了解俱乐部做什么 / 怎么加入
  • 现成员:查看活动公告 / 分享的项目 / 内部学习资源
  • 外部访客(企业 / 其他高校 / 媒体):看到俱乐部的实际产出与活跃度

技术栈

  • Vue 3 + Vite + TypeScript — SPA 框架 + 构建
  • Element Plus / 自研组件 — UI 库
  • 响应式布局 — PC / 移动端自适应
  • CI/CD — push 触发自动部署到 https://www.kcos.net.cn/

主要页面 / 功能

  • 首页:俱乐部介绍 + 当期活动 + 精选项目
  • 成员墙:现役成员展示(头像 / 方向 / GitHub)
  • 项目聚合:俱乐部维护 / 贡献的开源项目清单,各自详情页入口
  • 活动公告:workshop / 比赛 / 内部分享的时间线
  • 加入我们:申请流程 + 联系方式

上线地址

www.kcos.net.cn

后续

  • 仓库已稳定运行,后续工作集中在内容运营(项目 / 活动更新)与偶发的小型 UI 调整
  • 暂时不计划开源(私有仓库),本项目页是公开介绍,源码仅俱乐部成员可访问
