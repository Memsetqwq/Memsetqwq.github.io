本站本身即第一个项目 —— Neo-Editorial Dark 风格的个人项目展示门户 + 在线 Markdown 编辑器。

设计语言

  • 氛围:Neo-Editorial Dark(编辑刊物感 · 衬线斜体标题 · 米白文字 + 单点海军蓝强调)
  • 强调色:#2A3270 深海军蓝(取自个人头像)
  • 字体:Fraunces(variable serif,Display)+ Inter(variable sans,Body)+ JetBrains Mono(variable mono,导航 / Eyebrow / 编号)— 全部子集化自托管 woff2
  • 入场:3 秒 LoadingOverlay(序章 → 标题淡入 → 主屏淡出),无 P3R 风格视频

技术栈

  • 框架:Astro 5(static,View Transitions)
  • 样式:原生 CSS + CSS Variables(无 Tailwind)
  • 动效:零运行时动效库 — 波浪背景 / 入场动画 / 鼠标追踪全部原生 JS + CSS
  • Markdown 渲染(v0.2):VUE-md-Forge 的 MarkdownEngine SSR 替换默认 unified/remark,获得本地打包的 KaTeX + highlight.js + XSS 净化
  • 内容管理:Astro Content Collections(Markdown 驱动,src/content/projects/*.md)
  • 部署:GitHub Actions 自动构建到 GitHub Pages

项目结构

src/
├── Nav.astro              # 顶部导航(头像 + Memset + Works + Forge + social)
├── Hero.astro            # 首屏(7 字符字符级入场 + Morse 跑马灯)
├── ContactSection.astro  # 联系方式三卡片(GitHub / Email / WeChat)
├── LoadingOverlay.astro  # 首页加载屏(0~3s 序列)
├── WavesBackground.astro # 全屏 SVG 波浪 + 鼠标追踪
├── Icon.astro            # 统一图标组件
└── pages/
    ├── index.astro       # 首页
    ├── forge.astro       # 在线 Markdown 编辑器(v0.2)
    └── projects/         # 项目列表 + 详情
